\section*{1. Objective}

The objective of this experiment is to develop an end-to-end understanding of
recurrent sequence learning by implementing and comparing Vanilla RNN, LSTM
and GRU models. The experiment also introduces Backpropagation Through Time
(BPTT), the limitations of conventional RNNs, and the use of CNN-extracted
features with recurrent networks for video understanding.

The experiment uses the UCI Human Activity Recognition Using Smartphones
dataset as the primary sequence dataset. Students will prepare temporal input
sequences, visualize them, train RNN/LSTM/GRU models, compare their
performance, analyze convergence and generalization, and extend the pipeline
to video understanding using CNN feature extraction followed by an LSTM or
GRU.

A small synthetic sequence-to-sequence task is included at the end to
demonstrate the encoder--decoder framework.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

After completing this experiment, students will be able to:

\end{itemize}

\section*{7. Vanilla RNN Architecture}

A Vanilla RNN maintains a hidden state that is updated at every time step:

\[
h_t=\tanh(W_xx_t+W_hh_{t-1}+b_h).
\]

The output can be written as

\[
y_t=g(W_yh_t+b_y).
\]

For sequence classification, the final hidden representation can be passed
to a classifier.

\begin{center}
\begin{tikzpicture}[node distance=7mm]
\node[layer](x1){$x_1$};
\node[layer,right=of x1](h1){$h_1$};
\node[layer,right=of h1](x2){$x_2$};
\node[layer,right=of x2](h2){$h_2$};
\node[layer,right=of h2](x3){$\cdots$};
\node[layer,right=of x3](h3){$h_T$};
\node[layer,right=of h3](y){Softmax};

\draw[arrow](x1)--(h1);
\draw[arrow](h1)--(x2);
\draw[arrow](x2)--(h2);
\draw[arrow](h2)--(x3);
\draw[arrow](x3)--(h3);
\draw[arrow](h3)--(y);
\end{tikzpicture}
\end{center}

The diagram represents the unrolled view of an RNN. The same recurrent weights
are reused across time steps.

\section*{8. Backpropagation Through Time}

When an RNN is unrolled, the loss depends on the sequence of hidden states.
Backpropagation Through Time (BPTT) propagates the error backward through
the recurrent steps.

\begin{center}
\begin{tikzpicture}[node distance=5mm]
\node[smalllayer](a){$h_1$};
\node[smalllayer,right=of a](b){$h_2$};
\node[smalllayer,right=of b](c){$h_3$};
\node[smalllayer,right=of c](d){$\cdots$};
\node[smalllayer,right=of d](e){$h_T$};
\node[smalllayer,below=of e](l){Loss};

\draw[arrow](a)--(b);
\draw[arrow](b)--(c);
\draw[arrow](c)--(d);
\draw[arrow](d)--(e);
\draw[arrow](e)--(l);

\draw[arrow]($(e.south)!0.5!(l.north)$) to[bend right=35]
node[below,font=\scriptsize]{backward gradient} ($(a.south)!0.5!(b.south)$);
\end{tikzpicture}
\end{center}

Students should explain that repeated multiplication of derivatives through
many time steps can cause gradients to become extremely small or extremely
large.

\subsection*{Challenges}

\begin{itemize}
\item Vanishing gradients
\item Exploding gradients
\item Difficulty learning long-term dependencies
\item Sequential computation and limited parallelism
\end{itemize}

The vanishing-gradient problem can be conceptually represented as

\[
\left|\frac{\partial h_t}{\partial h_{t-k}}\right|\rightarrow0
\]

while exploding gradients correspond to very large gradient magnitudes.

\subsection*{Numerical Exercise}

Consider

\[
x_1=0.5,\qquad x_2=0.7,\qquad x_3=0.2,
\]

\[
h_0=0,\qquad W_x=0.5,\qquad W_h=0.8,\qquad b=0.1.
\]

Using

\[
h_t=\tanh(W_xx_t+W_hh_{t-1}+b),
\]

calculate $h_1$, $h_2$ and $h_3$ manually.

Students must compare their calculated values with the values obtained from
a program.

\textbf{Manual/program computation:}

\[
h_1=\tanh(0.5\times0.5+0.8\times0+0.1)=\tanh(0.350000)=0.336376
\]
\[
h_2=\tanh(0.5\times0.7+0.8\times0.336376+0.1)=\tanh(0.719100)=0.616352
\]
\[
h_3=\tanh(0.5\times0.2+0.8\times0.616352+0.1)=\tanh(0.693081)=0.599958
\]

Final hidden states: $[h_1,h_2,h_3]=[0.336376,\ 0.616352,\ 0.599958]$. These
values, obtained by direct computation, exactly match the values returned by
the program.

\textbf{Discussion (BPTT):} Because the same $W_h$ is repeatedly multiplied
across time steps during backpropagation, the gradient of the loss with
respect to earlier hidden states involves a product of many Jacobians. If
the dominant eigenvalue of that Jacobian is less than 1, the gradient
shrinks geometrically (vanishing gradient); if it is greater than 1, the
gradient grows geometrically (exploding gradient). Both effects make it
difficult for a Vanilla RNN to learn long-term dependencies, motivating the
gated LSTM/GRU architectures described next.

\section*{10. LSTM Architecture}

LSTM introduces a memory cell and gates to control information flow.

The forget gate is

\[
f_t=\sigma(W_f[h_{t-1},x_t]+b_f),
\]

the input gate is

\[
i_t=\sigma(W_i[h_{t-1},x_t]+b_i),
\]

and the output gate is

\[
o_t=\sigma(W_o[h_{t-1},x_t]+b_o).
\]

The candidate cell state is

\[
\tilde{C}_t=
\tanh(W_C[h_{t-1},x_t]+b_C),
\]

and the cell state is

\[
C_t=f_tC_{t-1}+i_t\tilde{C}_t.
\]

The hidden state is

\[
h_t=o_t\tanh(C_t).
\]

\begin{center}
\begin{tikzpicture}[node distance=5mm]
\node[layer](a){Input\\$x_t$};
\node[layer,right=of a](b){LSTM\\Cell};
\node[layer,right=of b](c){$h_t$};
\node[layer,above=of b](d){$C_t$};
\node[layer,right=of c](e){Classifier};

\draw[arrow](a)--(b);
\draw[arrow](b)--(c);
\draw[arrow](b)--(d);
\draw[arrow](c)--(e);
\draw[arrow](d)--(b);
\end{tikzpicture}
\end{center}

\textbf{Required inference:} Explain how the cell state and gates help the
network retain or discard information over long sequences.

The forget gate $f_t$ decides what fraction of the previous cell state
$C_{t-1}$ to discard, the input gate $i_t$ decides how much of the new
candidate $\tilde{C}_t$ to write in, and the output gate $o_t$ decides how
much of the (mostly linear) cell state to expose as the hidden state.
Because the cell state is updated by addition ($C_t=f_tC_{t-1}+i_t\tilde{C}_t$)
rather than repeated multiplication, gradients can flow through many time
steps largely unattenuated, which is why LSTM handles long-term dependencies
far better than a Vanilla RNN.

\section*{11. GRU Architecture}

GRU uses two principal gates:

\[
z_t=\sigma(W_z[h_{t-1},x_t]+b_z)
\]

and

\[
r_t=\sigma(W_r[h_{t-1},x_t]+b_r).
\]

The candidate hidden state is

\[
\tilde{h}_t=
\tanh(W_h[r_t\odot h_{t-1},x_t]+b_h).
\]

The hidden state is updated using

\[
h_t=(1-z_t)h_{t-1}+z_t\tilde{h}_t.
\]

\section*{22. Sequence-to-Sequence Learning}

Sequence-to-sequence learning maps one sequence to another.

For a simple laboratory task, construct a synthetic reversal dataset.

Example:

\[
[1,4,7,2]\rightarrow[2,7,4,1].
\]

Generate several thousand short sequences using integers from a fixed range.

The task is intentionally simple so that the encoder--decoder mechanism can
be studied without a large external dataset.

The encoder converts the input sequence into a learned representation.
The decoder generates the output sequence one element at a time.

\section*{27. Discussion Questions}

\begin{enumerate}
\item \textbf{What is a recurrent neural network?}\\
RNN is a neural network that contains a loop within neurons. It contains hidden states and the output depends on current input and previous state. It is used for sequential data processing. 

\item \textbf{What information is represented by the hidden state?}\\
Hidden state holds the overall memory of the network till the current node.

\item \textbf{Why is sequence order important?}\\
In a RNN, every output depends on the previous state. Sequence order is important to build the memory and pass it to the next layer and preserve the data. Sequence order ensures the sanity of the network. 

\item \textbf{Explain the difference between a feed-forward network and an RNN.}\\
A feed forward network passes the input across each layer without any memory. The output depends only on the current input.
\\RNN on the other hands maintains a memory, process the inputs sequentially and contains a loop.

\item \textbf{Explain Backpropagation Through Time.}\\
Backpropagation through time updates the weights across the sequence of data by computing gradients across multiple time steps. Then it creates a feed forward network and backpropagates. This minimizes the error and captures the temporal data and improves learning. 

\item \textbf{Why can gradients vanish during BPTT?}\\
Vanishing gradients in BPTT occurs due to consistent shrinking of gradients across time steps. This exponent shrinking with the number of time steps makes the gradient negligibly small for earlier time steps, leading to vanishing gradients.

\item \textbf{Why can gradients explode during BPTT?}\\
Larger weights exponentially grow across BPTT, across the sequence length. This produces very large gradient across the time steps, leading to exploding gradients.

\item \textbf{What are long-term dependencies?}\\
Long term dependencies in RNN is the ability of RNN to maintain past information and use the memory to current output, but RNN struggles in maintaining long term dependencies.

\item \textbf{What is the role of the LSTM cell state?}\\
The LSTM cell state maintains the information across the time steps, modified by logic gates. This enables LSTM to maintain long term informations without forgetting.

\item \textbf{What are the forget, input and output gates in LSTM?}\\
The forget gate controls how much of the previous cell state to hold or delete, the input gate controls how much of the new information to add into the cell state and the output gate controls how much of the updated cell state is passed to the hidden state or output.

\item \textbf{What are the reset and update gates in GRU?}\\
The reset gate controls how much of the previous hidden state to use when
computing the new hidden state and the update gate controls update between the previous hidden state and the new state.

\item \textbf{Compare LSTM and GRU.}\\
LSTM consists of forget, input and ouput gates and memory cells, making it more effective for very long time series data. LSTM is computationally intensive. GRU uses only input and output gates and do not contain a memory cell, making it computationally less intensive.

\item \textbf{Why does GRU generally use a simpler gating mechanism than LSTM?}\\
GRU uses a simpler gating mechanism to reduce the computational cost of LSTM, while still maintaining long term context and effective sequential data processing.

\item \textbf{Why should RNN, LSTM and GRU be compared using the same experimental settings?}\\
RNN, LSTM and GRU must be compared using same settings to ensure a fair comparison and understand the performance of each model.

\item \textbf{What does the confusion matrix reveal that accuracy alone does not?}\\
Confusion matrix reveals the classes among which the model gets confused and helps us understand which classes are classified always correctly and where the model fails.

\item \textbf{Why should macro F1-score be reported for multi-class classification?}\\
Macro F1 averages the F1-score of each class equally ensuring it is not dominated by few classes. It also reveals the classes where the model fails.

\item \textbf{What is the significance of sequence length?}\\
Sequence length determines the sequence of context that the model remembers. It is the knowledge capacity of the model. Shorter sequence reduces the model's performance due to lower memory whereas very long sequence increases computational cost and can lead to vanishing gradients.

\item \textbf{Why can a CNN be used as a feature extractor for video?}\\
Video is a collection of frames. CNN works well on large image datasets and using pre-trained CNN to video help in extracting spatial video frames without training the entire network from scratch.

\item \textbf{What type of information is extracted by the CNN?}\\
CNN extracts spatial information from a image. It cannot handle temporal information.

\item \textbf{What type of information is learned by the recurrent network?}\\
Recurrent networks learns temporal/sequential data.

\item \textbf{Why are CNN features arranged as a sequence before being given to LSTM/GRU?}\\
CNN features are arranges as sequence before feeding into Recurrent networks because these networks requires sequential data based on time steps or features.

\item \textbf{Explain the encoder and decoder in sequence-to-sequence learning.}\\
The encoder reads the entire input sequence and compresses it into a
state whereas decoder is
initialized from that state and generates the output sequence one element at a time.

\item \textbf{What is teacher forcing?}\\
Teacher training is a technique where the input is given as the actual ground truth instead of feeding the model's prediction. This reduces error and helps in faster convergence.

\item \textbf{Differentiate token accuracy and sequence accuracy.}\\
Token accuracy is the fraction of individual output positions predicted
correctly across all sequences whereas sequence accuracy is the fraction of entire
sequences predicted with every token correct. 

\item \textbf{Why must the test set remain untouched during model selection?}\\
Test set must remain isolated so as to prevent data leakage and bias and overfitting. The model must be trained to ensure optimal prediction for unseen data.
\end{enumerate}
